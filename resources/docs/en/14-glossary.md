---
title: Glossary
summary: The words used in the system, in plain language.
status: available
experts: education, design
---

| Word | Meaning |
|---|---|
| Need | Something a person is looking for. |
| Offer | Something a person can provide. |
| Match | A suggested fit between a need and an offer. It creates nothing by itself. |
| Deal | One real exchange followed from first contact to settlement. |
| Proposal | Terms put forward for discussion. |
| Agreement | A proposal that everyone accepted, version by version. |
| Version | One exact state of an agreement. Changes make new versions. |
| Rate | An agreed price for a unit of work, such as per square metre or per day. |
| Commitment | What a person has agreed to do. |
| Work report | A record of work done on a given day, with quantity and, if wanted, evidence. |
| Review | Looking at the result and accepting it or raising questions. |
| Obligation | An amount one person owes another. |
| Advance | Money paid before the work, kept as credit. |
| Settlement | Paying, adjusting or returning what is owed. |
| In kind | Settling with goods or services instead of money. |
| Book | A record of money: personal, shared, or for a project. |
| Confirm | The other person's acceptance of an entry you recorded. |
| Plan | Something you intend to do, with or without a schedule. |
| For later | A plan with no date and no reminder, until you schedule it. |
| Content | Documents and media you write and share. |
| Audience | Who may read a piece of content: only me, my contacts, or public. |
| Contact | A person you have chosen to share more with. |
| Group | A community with members and roles. |
| Business | An organisation with members that can act in deals. |
| Circuit | A closed loop of needs and offers in which what each person gives and receives is visible. |
