status: available

| واژه | معنا |
|---|---|
| نیاز | چیزی که کسی دنبالش است. |
| ارائه | چیزی که کسی می‌تواند فراهم کند. |
| تطبیق | یک سازگاری پیشنهادی میان یک نیاز و یک ارائه. خودش چیزی نمی‌سازد. |
| معامله | یک دادوستد واقعی که از اولین ارتباط تا تسویه دنبال می‌شود. |
| پیشنهاد | شرایطی که برای گفت‌وگو مطرح می‌شود. |
| توافق | پیشنهادی که همه نسخه‌به‌نسخه پذیرفته‌اند. |
| نسخه | یک وضعیت دقیق از توافق. هر تغییر نسخهٔ تازه می‌سازد. |
| نرخ | قیمت توافق‌شده برای یک واحد کار، مثلاً هر متر مربع یا هر روز. |
| تعهد | آنچه کسی پذیرفته انجام دهد. |
| گزارش کار | ثبت کار انجام‌شده در یک روز مشخص، با مقدار و در صورت لزوم مدرک. |
| بررسی | دیدن نتیجه و پذیرفتنش یا مطرح‌کردن پرسش. |
| طلب / بدهی | مبلغی که یک نفر به دیگری بدهکار است. |
| پیش‌پرداخت | پولی که پیش از کار پرداخت می‌شود و به‌صورت اعتبار نگه داشته می‌شود. |
| تسویه | پرداخت، تعدیل یا بازگرداندن آنچه بدهکاریم. |
| غیرنقدی | تسویه با کالا یا خدمت به‌جای پول. |
| دفتر حساب | ثبت پول: شخصی، مشترک یا برای یک پروژه. |
| تأیید | پذیرش طرف مقابل برای ردیفی که شما ثبت کرده‌اید. |
| برنامه | چیزی که قصد انجامش را دارید، با زمان‌بندی یا بدون آن. |
| برای بعد | برنامه‌ای بدون تاریخ و بدون یادآور، تا وقتی زمان‌بندی‌اش کنید. |
| محتوا | سند و رسانه‌ای که می‌نویسید و به اشتراک می‌گذارید. |
| مخاطب (دسترسی) | چه کسی می‌تواند یک محتوا را بخواند: فقط من، مخاطبانم، یا عمومی. |
| مخاطب (فرد) | کسی که انتخاب کرده‌اید چیزهای بیشتری با او به اشتراک بگذارید. |
| گروه | جامعه‌ای با اعضا و نقش‌ها. |
| کسب‌وکار | سازمانی با اعضا که می‌تواند در معامله‌ها عمل کند. |
| مدار | حلقه‌ای بسته از نیازها و ارائه‌ها که در آن آنچه هر نفر می‌دهد و می‌گیرد دیده می‌شود. |
